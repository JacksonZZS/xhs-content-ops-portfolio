# Resume Bullets

- Built an AI-assisted Xiaohongshu content operations studio using Next.js, Playwright, Gemini, Supabase, and Python, covering competitor analysis, inspiration memory, content generation, publishing, comment monitoring, and scheduling.
- Designed browser-automation and scraper fallbacks for fragile platform workflows, improving reliability beyond mock or API-only implementations.

- Refactored a private operator tool into a public portfolio repository by removing runtime artifacts, isolating environment-dependent paths, and documenting architectural tradeoffs.
